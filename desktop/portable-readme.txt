Mechano Download Manager (portable)
===================================
Nothing to install. Everything it needs is inside this folder.

1. Copy this whole "Mechano DM" folder anywhere (for example C:\Mechano DM or D:\Apps\Mechano DM).
   Keep all the files together.
2. Double-click "Mechano DM.exe" to start it.
3. Optional: double-click "Create desktop shortcut.cmd" for a desktop / Start-menu icon.
4. Browser button on videos (Chrome / Edge):
   open chrome://extensions, turn on "Developer mode", click "Load unpacked",
   and choose the "extension" folder inside this folder.

If Windows shows "Windows protected your PC" the first time: click "More info", then "Run anyway".
(The app is not signed with a paid certificate; that is the only reason for the warning.)
